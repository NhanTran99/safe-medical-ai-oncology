# Reviewer Notes

This Population Package establishes the foundational educational concept of **distant lymph node metastasis** and clarifies one of the most common misconceptions in TNM staging: **not every lymph node involved by gastric cancer is considered a regional lymph node**.

Future Population Packages should expand on:

- What Are Regional Lymph Nodes?
- What Are Distant Lymph Nodes?
- AJCC Regional Lymph Node Map
- Japanese Lymph Node Stations
- N Category
- M1 Classification
- Imaging for Distant Lymph Node Metastasis
- Lymph Node Biopsy
- Treatment of Distant Lymph Node Metastasis
- Prognosis of Distant Lymph Node Metastasis

without expanding or modifying the scope of this foundational package.
