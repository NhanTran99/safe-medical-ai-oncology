**Reason:**

Patients commonly assume that all lymph node involvement is equivalent. This Population Package explains the important distinction between **regional lymph nodes** and **distant lymph nodes**, providing the conceptual bridge between the N Category and M Category before introducing lymph node maps or staging rules.

## Typical Trigger Questions

- What is distant lymph node metastasis?
- Are all lymph nodes considered regional lymph nodes?
- What is the difference between regional and distant lymph nodes?
- Does cancer in any lymph node mean the same thing?
- Why is a lymph node classified as distant?
- How do doctors determine whether a lymph node is regional or distant?

---

## Retrieval Priority

**Very High**

**Reason:**

This concept is one of the most common sources of confusion for patients learning about TNM staging. It provides prerequisite knowledge for future Population Packages covering regional lymph node stations, AJCC nodal maps, M1 classification and staging interpretation.
