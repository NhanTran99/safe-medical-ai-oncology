# Educational Boundary Review

The Population Package successfully remains within the predefined educational boundary.

Included:

- definition of the N category;
- explanation of regional lymph nodes;
- relationship between N category and lymph node involvement;
- general relationship between increasing N category and disease extent;
- contribution of the N category to TNM staging, treatment planning and prognostic assessment;
- explanation that N category must always be interpreted together with T, M and other clinical information.

Excluded:

- N0–N3 classifications;
- number of positive lymph nodes;
- regional lymph node stations;
- D1 and D2 lymphadenectomy;
- sentinel lymph node concepts;
- AJCC Stage Groups;
- stage-specific prognosis;
- treatment recommendations according to N category.

The **Atomic Knowledge Principle** has been fully preserved.
