# Reviewer Notes

This Population Package extends the cancer staging pathway from **initial staging** to **longitudinal reassessment**. It clarifies that restaging is an updated evaluation performed to answer new clinical questions during the patient's cancer journey rather than a correction of the original stage. It provides the educational bridge to subsequent Population Packages on **RECIST**, **treatment response evaluation**, **ypStage**, and **surveillance after treatment**.
