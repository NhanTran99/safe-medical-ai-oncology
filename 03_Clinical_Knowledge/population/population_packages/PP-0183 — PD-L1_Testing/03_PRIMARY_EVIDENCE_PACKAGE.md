## 2. Clinical Question

> In gastric adenocarcinoma, what is PD-L1 testing, why and when is it performed, how is it assessed, what do PD-L1/CPS/TAP results mean, and how can those results influence immunotherapy selection?

## 3. Educational Intent

The package is intended to bridge the gap between a pathology/biomarker report and a clinically meaningful patient understanding.

It should enable a reader to understand:

- what is being tested;
- what specimen is used;
- what IHC means;
- what CPS means;
- why thresholds differ by treatment context;
- why the result matters;
- why the result is not sufficient by itself to prescribe treatment.

## 4. Scope

### Included

PD-L1 protein expression, FFPE tissue, IHC, specimen adequacy, companion-diagnostic context, CPS, CPS ≥1, treatment-contextual CPS ≥5, TAP, result interpretation, predictive versus prognostic role, multi-biomarker integration and patient-facing limitations.

### Excluded

Detailed PD-L1 biology, IHC technical protocols, detailed CPS/TAP scoring methodology, drug-specific treatment algorithms, dosing, toxicity, individualized decisions and detailed other-biomarker testing.

## 5. Primary Evidence Sources

### Source 1 — NCCN Gastric Cancer v2.2026

The supplied NCCN source states:

- a companion diagnostic should be used on FFPE tissue as an aid in identifying patients for treatment with PD-1/PD-L1 inhibitors;
- PD-L1 testing should be performed only in CLIA-approved laboratories;
- PD-L1 assessment is a qualitative IHC assay using anti-PD-L1 antibodies;
- the assay is performed on FFPE gastric adenocarcinoma tissue;
- at least 100 tumor cells must be present for the specimen to be considered adequate;
- PD-L1 expression is defined at CPS ≥1;
- CPS counts PD-L1-staining tumor cells, lymphocytes and macrophages relative to total viable tumor cells;
- CPS and TAP have high concordance and may be interchangeable in specified contexts.

Source: supplied file `1. Gastric Cancer_v.2.2026_NCCN-3-109.pdf`.

## 8. Evidence Notes

### Note A — Current guideline version controls

The project contains older and current NCCN material. For current PP-0183 recommendations, NCCN v2.2026 is the governing clinical anchor.

### Note B — Testing population wording

The current NCCN source specifies universal testing for newly diagnosed patients who are candidates for PD-1/PD-L1 inhibitor treatment. The package therefore should not use an unqualified statement that every gastric-cancer patient receives PD-L1 testing regardless of treatment intent.

### Note C — CPS threshold interpretation

CPS ≥1 is the guideline definition of PD-L1 expression in the stated framework. Higher thresholds can have different treatment implications. The package must not collapse these into one universal cutoff.

### Note D — TAP

TAP is included because it is explicitly present in the current NCCN v2.2026 biomarker framework. The package treats it as contextual rather than replacing the CPS-centered architecture.

### Note E — Prognosis

The NCCN discussion indicates uncertainty regarding PD-L1's standalone prognostic significance. The package therefore frames PD-L1 primarily as a predictive/treatment-selection biomarker.

## 9. Clinical Claims Summary

The evidence supports the following patient-facing synthesis:

> PD-L1 testing is a tumor-tissue biomarker assessment used to help guide selected immunotherapy decisions in gastric adenocarcinoma. The NCCN v2.2026 framework uses IHC on FFPE tumor tissue, with CPS as a principal scoring system and CPS ≥1 defining PD-L1 expression in the stated framework. The clinical meaning of higher scores depends on the specific treatment setting. PD-L1 is useful but imperfect and must be interpreted alongside other biomarkers and clinical factors.

## 11. Evidence Gaps

1. The supplied clinical source set does not establish a universal response probability for a given CPS.
2. The supplied sources do not justify a universal CPS threshold applicable to all treatment regimens.
3. Standalone prognostic significance remains uncertain.
4. TAP should not be generalized beyond the contexts supported by the current guideline.
5. Detailed assay performance characteristics are outside this package's scope.
6. Individual treatment eligibility cannot be determined from PD-L1 alone.
