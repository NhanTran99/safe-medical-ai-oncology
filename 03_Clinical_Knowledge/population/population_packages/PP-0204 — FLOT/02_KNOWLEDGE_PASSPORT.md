# Knowledge Classification

## Knowledge Type

Regimen-specific clinical education package.

## Atomic Clinical Question

> What is FLOT, how is it used in the perioperative treatment of resectable gastric/GEJ adenocarcinoma, what evidence supports it, and what should patients understand about treatment intensity, monitoring, and toxicity?

## Primary Function

To provide a reusable, patient-centered, evidence-traceable knowledge representation of FLOT without absorbing the broader ownership of perioperative chemotherapy, surgery, biomarker testing, immunotherapy, or toxicity-management packages.

**Regimen level.**

- perioperative chemotherapy as a strategy;
- systemic therapy as a treatment domain;

# Evidence Classification

## Established / Guideline-Supported

- FLOT composition.
- FLOT as preferred perioperative systemic therapy in the relevant NCCN setting.
- Need for patient selection based on fitness/performance status.
- Current recognition of FLOT-containing perioperative immunotherapy strategies.

## Established / Randomized Evidence

- FLOT4 randomized phase II/III evidence.
- Median OS 50 versus 35 months.
- HR 0.77.
- Margin-free resection 85% versus 78%.
- Phase II pathologic complete response 16% versus 6%.

## Established / Safety Evidence

- FLOT has important grade 3/4 infection, neutropenia, diarrhea, and neuropathy signals in the cited evidence.
- Treatment requires monitoring and can require adaptation.

## Context-Dependent

- exact implementation;
- treatment delays;
- dose modifications;
- regimen selection between FLOT and alternatives;
- FLOT + immunotherapy;
- biomarker-driven perioperative strategy.

## Not Owned by This PP

- individualized treatment decisions;
- detailed toxicity algorithms;
- detailed biomarker or immunotherapy selection.

## Boundary 7 — FLOT versus Immunotherapy

FLOT is chemotherapy.

Durvalumab or other immune checkpoint therapies are separate components owned by immunotherapy PPs.

# Runtime Decision Logic

If the user asks **“What is FLOT?”** → retrieve Definition + Components.

If the user asks **“Why FLOT before surgery?”** → retrieve Perioperative Context + Sequence.

If the user asks **“How many FLOT cycles?”** → retrieve FLOT4 sequence + reference regimen, while stating that actual delivery can be modified.

If the user asks **“Does FLOT cure cancer?”** → retrieve FLOT4 evidence + individual-prediction limitation.

If the user asks **“What are the side effects?”** → retrieve toxicity blocks; if detailed management is requested, delegate.

If the user asks **“Should I receive FLOT?”** → do not provide an individualized prescription; explain decision factors and direct to treating team.

If the user asks **“FLOT or immunotherapy?”** → explain that current treatment may combine chemotherapy and immunotherapy in selected settings; route detailed selection to immunotherapy/biomarker PPs.

# Safety / Uncertainty Rules

1. Never present reference dosing as a personalized prescription.
2. Never guarantee benefit.
3. Never guarantee completion of all planned cycles.
4. Never minimize FLOT toxicity.
5. Never treat a treatment delay as automatic treatment failure.
6. Never equate FLOT with all perioperative chemotherapy.
7. Never equate FLOT with immunotherapy.
8. Never use FLOT4 trial results as an individual survival prediction.
9. Preserve the distinction between established evidence and context-dependent implementation.
10. If source support is absent for a specific dosing or management detail, state that the supplied Source Materials do not establish it.
