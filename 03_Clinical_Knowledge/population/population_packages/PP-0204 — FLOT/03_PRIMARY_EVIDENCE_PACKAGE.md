# Clinical Question

## Primary Educational Question

> What is FLOT, how is it used as perioperative systemic therapy for resectable gastric/GEJ adenocarcinoma, what evidence supports its use, and what are the major patient-facing safety and treatment-tolerance concepts?

## Clinical-Educational Intent

Provide a source-traceable evidence base for a regimen-specific patient-facing package.

The evidence package must distinguish:

- current guideline position;
- randomized clinical evidence;
- practical regimen reference;
- patient-facing safety context;
- current but context-dependent treatment combinations.

# Detailed Evidence Notes

## Evidence Note 1 — FLOT Definition

The core definition is stable across the supplied NCCN and NCI materials.

FLOT is:

**fluorouracil + leucovorin + oxaliplatin + docetaxel.**

The supplied ACS source uses the same clinical naming.

## Evidence Note 2 — Perioperative Position

NCCN places perioperative systemic therapy within the treatment of localized resectable gastric cancer and lists FLOT as a preferred category-1 option.

Therefore FLOT is not merely a historical regimen.

## Evidence Note 3 — FLOT4 Population

The NCI PDQ describes 716 patients with stage IB to stage III resectable gastric or gastroesophageal adenocarcinoma.

This defines the major evidence context.

## Evidence Note 4 — Phase II FLOT4

The NCCN summary reports:

- pCR 16% FLOT;
- pCR 6% ECF.

It also reports a lower proportion of patients experiencing at least one grade 3–4 adverse event in the cited phase II comparison.

## Evidence Note 5 — Phase III FLOT4

The NCI PDQ reports:

- median OS 50 months FLOT;
- median OS 35 months ECF/ECX;
- HR 0.77;
- 95% CI 0.63–0.94;
- P = .012.

## Evidence Note 6 — Margin-Free Resection

The NCI PDQ reports:

- 85% FLOT;
- 78% ECF/ECX.

This is relevant because FLOT is given as part of a treatment strategy that includes surgery.

## Evidence Note 7 — Toxicity

NCI reports different toxicity patterns:

FLOT:
- grade 3/4 infections;
- neutropenia;
- diarrhea;
- neuropathy.

ECF/ECX:
- more nausea;
- thromboembolic events;
- anemia.

Hospitalization rates were similar in the cited comparison.

## Evidence Note 8 — Patient Fitness

NCCN states that FLOT has considerable toxicity and recommends use in selected patients with good performance status.

This is a central safety message.

## Evidence Note 9 — Reference Dosing

The supplied Vietnamese guideline provides a concrete FLOT reference:

- docetaxel 50 mg/m² day 1;
- oxaliplatin 85 mg/m² day 1;
- leucovorin 200 mg/m² day 1;
- 5-FU 1200 mg/m² over 24 hours on days 1–2;
- 14-day cycle;
- four cycles before and after surgery.

This should be labeled a **reference regimen**, not a universal patient-specific prescription.

## Evidence Note 10 — FLOT Versus FOLFOX/CAPOX

ACS lists FLOT, FOLFOX, and CAPOX among earlier-stage combinations.

The shared use of oxaliplatin does not make these regimens identical.

## Evidence Note 11 — Current Immunotherapy Context

NCCN v2.2026 includes FLOT + durvalumab among preferred perioperative systemic options in defined circumstances.

This is current context, not evidence that durvalumab is part of the FLOT acronym.

## Evidence Note 12 — Biomarker Context

NCCN includes biomarker-related perioperative treatment pathways, particularly MSI-H/dMMR and PD-L1/TAP-related circumstances.

PP-0204 should only acknowledge this interface.

## Evidence Note 13 — Metastatic FLOT

The supplied NCCN reference list includes a phase II study of biweekly FLOT in metastatic adenocarcinoma.

This is not the main evidence base for PP-0204 and is intentionally not used to define the core scope.

## Evidence Note 14 — Treatment Adaptation

The supplied ESMO-ASCO curriculum supports the general principles of toxicity monitoring and treatment adaptation.

The Source Materials do not support a single universal dose-modification algorithm for all patients.

## Evidence Note 15 — Individual Prediction

FLOT4 results are population-level trial outcomes.

They should not be used to predict that a specific patient will live exactly 50 months or experience exactly the reported relative hazard.

# Evidence Gaps

The supplied Source Materials do not establish:

1. a universal individualized FLOT dose calculator;
2. one universal dose-reduction table;
3. one universal treatment-delay threshold for every toxicity;
4. a universal antiemetic protocol;
5. a universal neuropathy algorithm;
6. a universal febrile-neutropenia protocol;
7. individualized probability of cure;
8. individualized probability of completing all cycles;
9. individualized benefit prediction;
10. universal FLOT versus FOLFOX/CAPOX selection criteria.

These gaps must remain explicit.

# Extended Evidence Interpretation

## Evidence Note 16 — Why the FLOT Acronym Matters

The acronym is not merely a memory aid.

Each letter identifies a treatment component, and the combination distinguishes FLOT from other gastric-cancer regimens.

The evidence should therefore be linked to the complete regimen rather than to any single drug.

## Evidence Note 17 — Why Leucovorin Must Remain in the Definition

Leucovorin is part of the FLOT regimen nomenclature and should not be silently omitted when defining the regimen.

The NCI PDQ describes FLOT as docetaxel, oxaliplatin, and 5-FU/leucovorin.

## Evidence Note 18 — Why Reference Dosing Needs a Caveat

The supplied Vietnamese guideline gives concrete dosing.

However, dose information in a population knowledge package can be misunderstood as a prescription.

Therefore the package deliberately labels it:

> **source-supported reference regimen**

rather than:

> **patient-specific recommended dose**.

## Evidence Note 19 — Why the 14-Day Cycle Is a Core Concept

The cycle interval affects:

- treatment planning;
- recovery;
- toxicity monitoring;
- coordination with surgery.

It is therefore clinically meaningful and not merely administrative metadata.

## Evidence Note 20 — Why Four + Four Should Be Presented as a Framework

The FLOT4 perioperative design used four cycles before and four after surgery.

This should be explained as:

> the trial regimen framework.

It should not be transformed into an absolute rule that every patient must receive exactly eight cycles.

## Evidence Note 21 — Why the Comparator Matters

The FLOT4 comparator was ECF/ECX.

Without the comparator, the statement “FLOT improved survival” loses the context required to interpret the effect.

Therefore all efficacy claims should identify the comparison where relevant.

## Evidence Note 22 — Why the OS Result Is More Important Than a Single Response Rate

Overall survival is a clinically meaningful endpoint.

The phase III FLOT4 result:

**50 vs 35 months**

provides the principal survival evidence supporting the regimen.

## Evidence Note 23 — Why pCR Is Supporting Rather Than the Sole Evidence

The phase II pCR finding is important because it provides a pathological treatment-response signal.

However, the phase III OS result provides the stronger survival anchor.

Therefore the package does not define FLOT's value solely by pCR.

## Evidence Note 24 — Why Margin-Free Resection Is Relevant

FLOT is integrated with surgery.

A higher margin-free resection proportion in FLOT4 provides a relevant surgical outcome associated with the perioperative treatment strategy.

However, it does not mean FLOT itself performs the surgery or guarantees a clear margin in an individual patient.

## Evidence Note 25 — Why Toxicity Is Part of the Evidence Balance

Efficacy cannot be interpreted separately from toxicity.

FLOT4 showed that toxicity patterns differed between FLOT and ECF/ECX.

NCCN therefore emphasizes patient fitness.

The knowledge package should preserve this benefit-risk relationship.

## Evidence Note 26 — Why Hospitalization Rates Need Careful Interpretation

NCI reports similar hospitalization rates in the cited comparison:

- 26% ECF/ECX;
- 25% FLOT.

This does not mean the regimens had identical toxicity.

The types of adverse events differed.

## Evidence Note 27 — Why “FLOT Is Safer Than ECF” Is Not a Valid Summary

The evidence does not support a simple global statement that FLOT is “safer.”

Different adverse-event patterns occurred.

FLOT had higher rates of some clinically important toxicities.

Therefore the appropriate summary is:

> FLOT and ECF/ECX had different toxicity profiles, while FLOT produced the survival benefit reported in FLOT4.

## Evidence Note 28 — Why Current NCCN Position Matters

The current guideline translates the historical randomized evidence into present-day practice.

NCCN v2.2026 continues to list FLOT as a preferred category-1 perioperative regimen in the relevant setting.

This supports continued relevance of PP-0204.

## Evidence Note 29 — Why Current Guideline Context Does Not Erase Trial Context

A guideline recommendation is not itself a clinical trial.

The package therefore preserves:

**trial evidence**

and

**current guideline interpretation**

as distinct evidence layers.

## Evidence Note 30 — Why FLOT + Durvalumab Is Not Evidence That FLOT Alone Is Obsolete

Current NCCN guidance includes FLOT + durvalumab in defined circumstances.

This represents evolution of the perioperative treatment strategy.

It does not negate FLOT4 evidence or remove FLOT as a chemotherapy backbone.

## Evidence Note 31 — Why Biomarker-Driven Treatment Requires Separate Ownership

A biomarker may influence whether an immunotherapy-containing strategy is considered.

That is different from saying that the biomarker “selects FLOT.”

Therefore biomarker testing remains an adjacent package.

## Evidence Note 32 — Why FLOT4 Cannot Be Used to Answer Every Current Treatment Question

FLOT4 can support:

- FLOT versus ECF/ECX;
- survival;
- selected pathological/surgical outcomes;
- toxicity.

It cannot by itself answer:

- current optimal immunotherapy combination for every subgroup;
- individualized dose selection;
- current management of every toxicity;
- every alternative chemotherapy comparison.

## Evidence Note 33 — Why the Source Set Supports a Regimen-Level Package

The supplied materials collectively cover:

- guideline positioning;
- randomized evidence;
- patient-facing explanation;
- practical regimen reference;
- general oncology treatment principles.

This is sufficient for a robust FLOT Population Package without importing unsupported clinical protocols.

# Evidence-to-Knowledge Translation Rules

## Rule 1

Trial data must be presented as trial data.

## Rule 2

Guideline recommendations must be presented as guideline recommendations.

## Rule 3

Reference dosing must be presented as reference dosing.

## Rule 4

Patient-facing statements must not overstate certainty.

## Rule 7

# Evidence Limitations

## Population Limitation

FLOT4 enrolled selected patients meeting trial eligibility criteria.

## Setting Limitation

The core evidence is for resectable gastric/GEJ adenocarcinoma in the perioperative setting.

## Comparator Limitation

The strongest direct randomized comparison is with ECF/ECX.

## Implementation Limitation

The exact regimen delivered in practice may be adapted.

## Patient-Specific Limitation

The trial does not provide individualized predictions.

## Evolving-Landscape Limitation

Current immunotherapy combinations can alter treatment strategy for selected patients.

# Evidence Decision

- regimen definition;
- regimen structure;

- major toxicity;
- guideline position;
- patient-facing education.

The source set is insufficient to support:

- universal individualized dose adjustment;
- individualized treatment prediction;
- universal toxicity algorithms.

The package respects that distinction.
