# Reviewer Notes

This Population Package completes the **foundational cancer staging sequence** begun with **PP-0090 (TNM Staging)**. It introduces Stage I–IV as broad stage groups while preventing the common misconception that stage numbers have identical meanings across different cancer types. It provides the educational bridge to **Clinical Stage vs Pathological Stage**, **Stage IA/IB**, and disease-specific staging systems.
