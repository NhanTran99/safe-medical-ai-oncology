# 03_PRIMARY_EVIDENCE_PACKAGE --- PP-0200 D1 Lymphadenectomy

## Clinical Question

> What is D1 lymphadenectomy in gastric cancer, which regional lymph
> nodes does it include, when may it be used, how does it differ from
> D1+ and D2, and what does it mean for staging and oncologic surgery?

## Scope

### Included

-   D1 anatomical definition.
-   Regional/perigastric lymph-node field.
-   Station-based D1 classification supported by the supplied Vietnamese
    guideline.
-   D1+ and D2 as comparative extensions.
-   D1 and gastrectomy.
-   Selected clinical contexts for D1.
-   Early gastric cancer and endoscopic alternatives.
-   Lymph-node examination and the ≥16-node goal.
-   Nodes removed vs examined vs positive.
-   Pathological staging interface.
-   Curative versus palliative context.
-   Patient-facing interpretation.
-   Common misconceptions.

### Excluded

-   Detailed D2 package content.
-   Sentinel lymph-node methodology.
-   Detailed EMR/ESD criteria and technique.
-   Operative step-by-step dissection.
-   Detailed pathology processing.
-   Systemic treatment.
-   Individualized treatment selection.
-   Individualized prognosis.

## Primary Sources

### Source 1 --- NCCN Guidelines Version 2.2026, Gastric Cancer

Primary evidence for:

-   definition of D1;
-   definition of D2;
-   regional lymph-node removal with gastric resection;
-   ≥16 lymph-node examination goal;
-   selected early gastric cancer/endoscopic context;
-   minimally invasive surgical context;
-   splenectomy principles;
-   palliative surgery context;
-   D1/D2 comparative evidence discussion.

The source states that D1 entails gastrectomy with removal of greater
and lesser omenta and includes the right/left cardiac, lesser/greater
curvature, suprapyloric and infrapyloric nodal regions. It separately
states the goal of examining ≥16 lymph nodes.

### Source 2 --- Vietnamese gastric-cancer diagnosis and treatment guideline

Primary supporting source for:

-   station-based D1/D1+/D2 classification;
-   D1 as groups 1--7;
-   D1+ as an extension of D1;
-   stage-linked clinical context for selecting D1 versus broader
    dissection.

## Evidence Interpretation

### 1. Anatomical extent is the defining concept

The strongest current guideline anchor defines D1 by the regional nodal
territory removed during gastrectomy.

This is the primary definition used in the CKO.

### 2. Node count is a separate dimension

The NCCN surgical framework separately specifies a goal of examining at
least 16 lymph nodes.

This creates three distinct variables:

1.  anatomical extent of dissection;
2.  number of lymph nodes examined;
3.  number of positive lymph nodes.

The package deliberately preserves this distinction.

### 3. Station terminology requires source attribution

The Vietnamese guideline supplies a station-based framework in which D1
is groups 1--7.

The package should use that terminology as a source-attributed
classification rather than inventing a universal crosswalk that is not
directly documented in the supplied evidence.

### 4. D1 is not the same as D2

D2 extends beyond the D1 regional/perigastric field.

The D2 comparison is necessary to explain the meaning of D1 but does not
transfer D2 ownership into this package.

### 5. D1 is not a universal early-cancer operation

NCCN identifies selected Tis/T1a mucosal lesions as possible candidates
for endoscopic resection.

Therefore the clinical pathway must be understood as disease-dependent.

### 6. Lymphadenectomy is linked to staging

The NCI source provides the relationship between regional lymph-node
metastasis and N classification.

This supports the package's explanation of why lymph-node examination
matters.

### 7. Palliative intent is different

The NCCN source states that palliative gastric resection for incurable
disease does not need to include lymph-node dissection.

This prevents the runtime from describing D1 as mandatory in every
operation.

## Detailed Evidence Notes

### D1 and regional lymphatics

NCCN describes gastric resection with regional lymph-node removal and
specifies D1 as the regional/perigastric extent.

This provides the primary evidence for the definition.

### D1 and D2

NCCN defines D2 as D1 plus lymph nodes along named arteries of the
celiac axis.

This is used only to define the upper boundary of PP-0200.

### D1 and ≥16 nodes

The package must avoid conflating the anatomical operation with the
pathology count.

The NCCN wording supports a separate examination goal.

### D1 and early gastric cancer

The NCCN source permits an endoscopic pathway for selected Tis/T1a
lesions.

The package therefore describes D1 as part of the surgical pathway when
surgery is appropriate, not as an automatic requirement for all early
disease.

### D1 and splenectomy

The NCCN source states routine splenectomy is not indicated unless
specific involvement or extensive hilar adenopathy is present.

This supports the package's organ-preservation misconception safeguard.

### D1 and palliative surgery

The NCCN source states that palliative gastric resection does not need
to include lymph-node dissection.

This creates an explicit boundary between curative oncologic surgery and
symptom-directed palliation.

## Clinical Uncertainty and Context

The supplied sources demonstrate that D1/D2 practice has evolved and
differs across regions.

NCCN describes D2 as standard for curable gastric cancer in East Asia,
while historical Western randomized trials did not show a simple
overall-survival advantage for D2 over D1 and reported greater morbidity
and mortality in the historical D2 setting.

The package should therefore avoid simplistic statements such as:

-   "D1 is obsolete."
-   "D2 is always superior."
-   "D1 is always safer."

The appropriate extent is a clinical decision that depends on disease
characteristics, surgical expertise, center experience, and the
guideline framework being used.

## Patient-Facing Evidence Translation

### What the patient needs to know

D1 means that the operation includes removal of a defined group of
nearby regional lymph nodes.

### What the patient does not need to infer

The patient should not infer the exact operation from the number of
nodes in the pathology report alone.

### What the pathology report adds

It tells the clinical team how many nodes were examined and whether
cancer was found in them.

### What the surgeon's report adds

It documents the anatomical operation and lymph-node dissection
performed.

## Evidence Gaps

The supplied project materials are sufficient for the approved PP-0200
scope.

The source set does not provide a complete operative manual for every D1
nodal station, and the package therefore does not invent one.

The source set also does not justify universal individualized rules for
selecting D1 in every patient.

These gaps are intentionally preserved.

not be generalized.

## Comparative D1/D2 Evidence Context

NCCN summarizes historical Western randomized evidence in which D2 had
higher postoperative morbidity and mortality in the Dutch trial setting
without a significant overall-survival difference.

The long-term analysis showed lower local and regional recurrence and
fewer gastric-cancer deaths with D2 but similar overall survival.

This evidence should be interpreted carefully because:

-   surgical quality has evolved;
-   center expertise differs;
-   practice differs by region;
-   D2 is technically more extensive.

The correct evidence message for PP-0200 is therefore:

> **D1 and D2 are different surgical extents; comparative benefit
> depends on clinical and system context.**

The full comparative evidence belongs to PP-0201.
