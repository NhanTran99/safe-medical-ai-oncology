# 2. Clinical Question

> What is a sentinel lymph node in gastric cancer, why might sentinel-node assessment be considered, how does it differ from D1/D2 lymphadenectomy, and what limitations must be understood before it is used as a clinical decision strategy?

# 5. Primary Evidence Sources

## 5.1 NCCN Gastric Cancer v2.2026

Primary source for the surrounding gastric surgical framework.

The source states that gastric resection should include regional lymph-node removal and describes D0, D1, and D2 by extent. It defines D1 as the perigastric field and D2 as D1 plus nodes along the left gastric, common hepatic, celiac, and splenic arteries.

The source also states that D2 requires significant training and expertise and should be performed in experienced centers.

The source therefore establishes the comparator framework against which PP-0202 must define sentinel-node assessment.

**Use in PP-0202:** high authority for gastric regional nodal surgery.

**Limitation:** the supplied material does not provide a dedicated gastric sentinel-node evidence framework.

---

## 5.2 NCI Gastric Cancer Treatment PDQ

NCI provides independent gastric-cancer treatment context.

The source describes surgical resection with regional lymphadenectomy for appropriate localized gastric cancer and discusses stage I treatment, including selected endoscopic resection.

**Use in PP-0202:** establishes the importance of regional nodal management and the early-disease context.

**Limitation:** the supplied material does not establish a gastric sentinel-node protocol.

# 8. Evidence Notes

## 8.1 D1/D2 is the established gastric comparator

The NCCN source is explicit that gastric lymph-node dissection is classified by anatomical extent.

This gives PP-0202 a strong boundary:

> sentinel-node assessment must not be written as another D-level.

---

## 8.2 D2 is an anatomical operation

NCCN describes D2 using named arterial territories.

Therefore D2 is not defined by a simple node count.

This is relevant to PP-0202 because a sentinel-node strategy also cannot be reduced to a node-count concept.

---

## 8.3 Early gastric cancer creates a relevant clinical question

The supplied gastric sources describe selected early cancers that may be managed endoscopically and also describe regional lymphadenectomy as part of surgical management.

Therefore the project evidence supports the existence of the **clinical tension**:

> local treatment versus the need to understand regional nodal disease.

It does not establish that sentinel-node assessment resolves this tension safely in all patients.

# 10. Clinical Claims Summary

## Established

- Regional lymph nodes matter in gastric cancer.
- Regional lymphadenectomy is a major component of curative gastric surgery.
- D1 and D2 represent different anatomical extents.
- D2 is broader than D1.
- D2 requires expertise.
- Selected early gastric cancers may receive endoscopic treatment.

## Conceptual / setting-dependent

- Sentinel-node assessment seeks representative draining nodes.
- Selective nodal assessment may be attractive when avoiding unnecessary extensive surgery is clinically relevant.
- False-negative risk is the key safety issue.
- Sentinel-node results require pathology.
- The clinical value depends on validated selection and accuracy.

## Not established from the supplied source set

- universal gastric sentinel-node protocol;
- numerical diagnostic accuracy;
- universal eligibility;
- universal replacement of D1/D2;
- universal oncologic equivalence.

# 13. Evidence Consistency Review

The package is internally consistent because it preserves the following distinctions:

### Anatomical field versus selective strategy

D1/D2 = field lymphadenectomy.

Sentinel node = selective nodal strategy.

### Established gastric evidence versus missing sentinel evidence

The package uses gastric sources for gastric claims.

It does not use non-gastric sentinel-node evidence to create gastric recommendations.

### Concept versus treatment algorithm

The package explains why sentinel-node strategies are clinically interesting.

It does not prescribe when a patient should personally undergo one.

### Negative result versus certainty

The package does not equate a negative sentinel node with absence of all regional nodal disease.

# 14. Patient-Facing Evidence Translation

## Question: “Why are lymph nodes important?”

Because stomach cancer can spread to regional lymph nodes, and lymph-node findings help determine disease stage and subsequent management.

## Question: “What is a sentinel node?”

It is a node among the first nodes receiving lymphatic drainage from the tumor.

## Question: “Is it the same as D2?”

No. D2 is a defined regional lymph-node dissection. Sentinel-node assessment is a selective strategy.

## Question: “If it is negative, am I definitely node-negative?”

Not automatically. The reliability of that conclusion depends on the validated performance of the sentinel-node strategy in the relevant setting.

## Question: “Can I avoid D2 if the sentinel node is negative?”

That is an individualized surgical decision and is not determined by this PP.
