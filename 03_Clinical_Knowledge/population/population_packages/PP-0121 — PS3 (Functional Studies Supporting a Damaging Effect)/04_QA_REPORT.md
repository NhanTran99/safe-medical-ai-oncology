# Reviewer Notes

This Population Package introduces **PS3**, one of the core experimental evidence categories within the ACMG/AMP framework, by explaining in patient-friendly language how **well-established functional studies** can contribute strong evidence during variant interpretation. It carefully distinguishes **experimental evidence** from **clinical diagnosis**, emphasizing that only rigorously validated functional studies are considered and that PS3 always represents **one component of a broader evidence-based evaluation**. Technical laboratory methodologies, assay validation procedures, and ClinGen implementation guidance remain appropriately deferred to future Population Packages, preserving full compliance with the **Atomic Knowledge Principle**.
