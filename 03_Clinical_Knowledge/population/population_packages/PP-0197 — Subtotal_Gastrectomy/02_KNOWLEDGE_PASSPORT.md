## Knowledge Classification

## Knowledge Type

Patient-facing education about a specific surgical treatment for gastric cancer.

## Atomic Clinical Question

> **What is subtotal gastrectomy, when can it be used for gastric cancer, why might it be chosen instead of total gastrectomy, and what should a patient understand about the operation and its consequences?**

## Primary Function

This PP is the **specific subtotal-gastrectomy node** between general gastrectomy principles and downstream surgical/treatment packages. It translates the oncologic rationale of partial stomach removal into a patient-understandable model without becoming an operative manual.

## Evidence Classification

### Established / Guideline-Supported

- Subtotal gastrectomy is an established surgical option for appropriately selected gastric cancers.
- Distal subtotal gastrectomy is used for selected distal/lower gastric lesions.
- Proximal subtotal gastrectomy is used in selected proximal/cardia situations.
- Adequate gastric resection with negative microscopic margins is a core oncologic principle for resectable disease.
- Regional lymphadenectomy accompanies curative gastric resection in guideline frameworks.
- Routine splenectomy is not indicated solely because gastrectomy is performed.
- Minimally invasive approaches may be considered in selected patients with experienced surgeons.
- Long-term nutritional and functional consequences can occur after gastrectomy.

### Supported but Context-Dependent

- exact extent of gastric resection
- exact margin distance
- distal versus proximal subtotal approach
- open versus minimally invasive approach
- extent of lymphadenectomy
- adjacent-organ resection
- feeding support
- palliative gastric resection

### Not Owned by This PP

- D1/D2 technical methodology
- reconstruction technique
- systemic treatment selection
- individualized nutritional treatment
- individualized prognosis

## Evidence Gaps

- Project sources do not support one universal numeric margin rule applicable to every gastric cancer.
- The precise reconstruction selected for an individual patient is not determined by this educational package.
- The precise extent of lymphadenectomy is disease- and guideline-context dependent.
- Long-term nutritional management requires individualized clinical assessment.
- Minimally invasive suitability depends on disease extent, expertise, and local capability.
- Individual prognosis cannot be inferred from the operation name alone.

## Runtime Answer Calibration

### If user asks a definition
Start with part-versus-whole distinction, then explain why preservation may be possible.


### If user asks why subtotal
Explain location, extent, margin adequacy and selected subtotal-versus-total evidence.


### If user asks about surgery technique
Give only conceptual description and redirect detailed technique to the surgical team/dedicated package.


### If user asks about lymph nodes
Explain regional lymphadenectomy concept; do not reproduce D1/D2 station detail.


### If user asks about eating
Explain reduced capacity and possible need for smaller meals; avoid individualized diet prescriptions.


### If user asks about prognosis
Do not infer prognosis from subtotal gastrectomy alone.


### If user asks about chemotherapy
Explain that surgery can be integrated with perioperative/adjuvant treatment; do not prescribe a regimen.


### If user asks about recurrence
Explain that negative margins are important but do not guarantee no recurrence; detailed surveillance is downstream.
