# Clinical Question

**Primary Educational Question**

> **What are PM Evidence Codes (Moderate Pathogenic Evidence)?**

---

# Educational Intent

Provide patients and caregivers with an accurate, evidence-based explanation of **PM Evidence Codes (Moderate Pathogenic Evidence)** as one of the standardized **ACMG/AMP evidence-code families**.

This Population Package explains that **PM (Pathogenic Moderate) Evidence Codes represent moderate scientific evidence supporting pathogenicity.** Each PM code corresponds to a different category of moderate evidence and contributes to structured variant interpretation. PM evidence codes are interpreted together with stronger, weaker, and benign evidence categories and are **never interpreted as independent diagnostic conclusions.**

# Clinical Claims Summary

The evidence consistently supports the following educational messages:

- PM Evidence Codes represent moderate evidence supporting pathogenicity.
- The PM family contains multiple individual evidence codes.
- Each PM code captures a different type of scientific evidence.
- PM evidence contributes to the overall interpretation of a genetic variant.
- Final variant classification always requires comprehensive professional evaluation.

---

# Evidence Consistency Review

No clinically meaningful disagreement was identified among the primary references.

Professional organizations consistently recognize the **PM (Pathogenic Moderate)** evidence-code family as one of the standardized pathogenic evidence-strength categories within the ACMG/AMP variant interpretation framework. Guidance consistently explains that each PM code represents a distinct category of moderate scientific evidence and that PM evidence is interpreted together with all other available evidence. ClinGen SVI recommendations further refine the application of individual PM evidence codes while emphasizing that **PM evidence contributes to—but does not independently determine—the final variant classification.**
