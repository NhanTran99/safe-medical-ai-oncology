# Scope Verification

This Population Package intentionally focuses only on the **bystander effect** as a conceptual feature of some antibody-drug conjugates (ADCs).

The following topics are intentionally excluded and delegated to future Population Packages:

- Molecular diffusion
- Membrane permeability
- Payload chemistry
- Cleavable versus non-cleavable linker comparison
- Intracellular drug release
- Toxicity mechanisms
- Drug-specific comparisons
- Pharmacokinetics
- Resistance mechanisms
- Clinical trial interpretation

This satisfies the Gold Population Package principle of **Atomic Knowledge (Single Educational Question).**
