# Reviewer Notes

This Population Package introduces **PM5**, one of the core **Moderate Pathogenic Evidence** codes within the ACMG/AMP framework, by explaining how **existing knowledge about one pathogenic missense variant** can inform the evaluation of a **different missense variant affecting the same amino acid position**. The package clearly emphasizes that **shared residue location does not imply identical biological consequences**, preventing a common misconception while maintaining scientific accuracy. Advanced concepts—including amino acid chemistry, missense biology, protein structural analysis, functional assays, evolutionary conservation, and ClinGen implementation guidance—are intentionally deferred to dedicated Population Packages, preserving strict adherence to the **Atomic Knowledge Principle**.
