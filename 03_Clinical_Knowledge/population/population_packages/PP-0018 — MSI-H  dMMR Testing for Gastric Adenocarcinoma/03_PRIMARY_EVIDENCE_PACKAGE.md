# Clinical Question

**Primary Educational Question**

> What is MSI-H / dMMR testing and why is it important in the treatment of gastric adenocarcinoma?

---

# Educational Intent

Provide patients and caregivers with an evidence-based understanding of MSI-H / dMMR testing as an important biomarker assessment used in precision oncology for gastric adenocarcinoma.

This Population Package explains why MSI-H / dMMR testing is performed, when it is recommended, how the results contribute to treatment planning and why these biomarkers are particularly relevant when immunotherapy is being considered.

It serves as the prerequisite before introducing MSI biology, mismatch repair mechanisms, Lynch syndrome and molecular testing methodologies.

# Clinical Claims Summary

The evidence consistently supports the following educational messages:

- MSI-H / dMMR testing is an important biomarker assessment in modern gastric cancer care.
- MSI-H / dMMR testing helps personalize immunotherapy decisions.
- MSI-H / dMMR-positive and MSS/pMMR results should always be interpreted within the overall clinical context.
- These biomarkers represent one component of comprehensive precision oncology.
- Testing is commonly performed using tumor tissue.
- Patients benefit from understanding how MSI-H / dMMR results contribute to shared treatment decision-making.

# Evidence Consistency Review

No clinically meaningful disagreement was identified among the primary authoritative references.

All major references consistently recommend MSI-H / dMMR testing as an important biomarker assessment for appropriate patients with gastric adenocarcinoma.

Differences among references primarily involve:

- laboratory methodology;
- molecular testing approaches;

- educational wording.

The Clinical Knowledge Object follows:
