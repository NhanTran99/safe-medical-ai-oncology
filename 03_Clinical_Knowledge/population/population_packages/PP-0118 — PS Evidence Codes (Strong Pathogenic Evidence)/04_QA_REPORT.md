# Reviewer Notes

This Population Package expands the repository's **ACMG evidence hierarchy** by introducing the **PS evidence-code family** as the second major pathogenic evidence category following **PVS1**. It establishes the important conceptual distinction between an **evidence-code family (PS)** and the **individual evidence codes (PS1–PS4)** that belong to it. By emphasizing that strong evidence contributes to—but does not independently determine—variant classification, this package preserves the integrity of the ACMG evidence framework and prepares the repository for the detailed exploration of each individual PS evidence code.
