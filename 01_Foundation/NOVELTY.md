# 1. PURPOSE

This document records the project's unique innovations (novelties) and their development status.

It serves as the authoritative reference for the project's scientific, technical, clinical, and portfolio differentiation.

This document is intended to evolve throughout the project lifecycle as concepts mature into implemented and validated components.

---

# 2. NOVELTY CLASSIFICATION

Project novelties are organized into four categories.

## Scientific Novelty

Research contributions that may support publications, grant proposals, or academic dissemination.

---

## Technical Novelty

Innovations related to AI architecture, software engineering, safety, and explainability.

---

## Clinical Novelty

Innovations that improve the safety, transparency, and usability of AI for oncology patient education.

---

## Portfolio Novelty

Features that strengthen the project's value as a flagship portfolio for PhD applications, research collaborations, and academic presentations.

---

# 3. NOVELTY MATURITY SCALE

Each novelty is assigned one of the following maturity levels.

- Approved Concept
- Designed
- Implemented
- Validated

The maturity level should be updated as the project progresses.

# 5. DESIGN PRINCIPLES

Every novelty should satisfy at least one of the following objectives.

- Improve patient safety.
- Improve explainability.
- Improve evidence transparency.
- Improve clinical usability.
- Improve scientific contribution.
- Improve software maintainability.

Novel features should not be introduced solely for technical complexity.
